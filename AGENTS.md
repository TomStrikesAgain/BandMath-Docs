# Knowledge Base Team Domain Rules (BandMath-Docs)

You are operating within the **Knowledge Base Team** domain for BandMath. This repository contains the public customer-facing documentation, user guides, and knowledge base web application built with [Docusaurus](https://docusaurus.io/).

---

## 🎯 Domain Scope & Team Jurisdiction

* **Team:** Knowledge Base Team
* **Primary Responsibilities:** Organizing documentation architecture, authoring user guides, maintaining the Docusaurus web app, ensuring local search functionality, and managing localization.
* **Team Boundaries & Invariants:**
  1. **Legal Documents Auto-Sync Invariant:** Do **NOT** manually edit `docs/Privacy_Policy.md` or `docs/98_Terms_of_Service.md`. The `prebuild` and `prestart` hooks automatically run `scripts/fetch-legal.js` to pull authoritative legal copy directly from the Supabase database (`public.legal_documents`). All legal changes belong exclusively to the **Legal Team** via the `bandmath-legal-workflow` skill.
  2. **Automated Visual Asset Pipeline:** Do **NOT** capture ad-hoc or inconsistent manual screenshots. UI screenshots are deterministically generated by the **Testing Team** E2E test runs (`test_helpers.dart`).

---

## ⚡ The Mandatory Verification Gate

**CRITICAL INVARIANT:** Before declaring any documentation task complete or committing changes, you **MUST** run a full build check:

```bash
npm run build
```

* **Zero Broken Links:** Docusaurus is configured with `onBrokenLinks: 'throw'`. Any broken relative link, missing anchor, or invalid route will fail the build immediately.
* **Asset Integrity:** Every image path (e.g., `![Caption](./assets/...)`) must physically exist on disk before the build can succeed.
* **Local Preview:** To preview changes interactively, run:
  ```bash
  npm run start
  ```

## 📝 Authoring & Formatting Standards

### 1. Docusaurus Admonitions
Do **NOT** use standard GitHub markdown alerts (`> [!NOTE]`). Use native Docusaurus admonition containers:

```markdown
:::note
Informational context or background notes.
:::

:::tip
Pro-tips, best practices, or workflow accelerators for musicians on tour.
:::

:::danger
Irreversible financial or data actions (e.g., deleting bands or resetting ledgers).
:::
```

### 2. Exclusive Single-Open FAQ Accordions
When writing or updating FAQs, use the native HTML `<details name="...">` element. Providing identical `name` attributes guarantees that only one accordion item expands at a time:

```html
<details name="faq_accordion">
<summary>How do I upgrade my subscription?</summary>

All subscriptions are managed securely via our web portal at [account.itsbandmath.com](https://account.itsbandmath.com)...

</details>
```

### 3. Contact Email Copy Button
Do **NOT** use raw `mailto:` links (they trigger unexpected system email clients). Use the interactive copy-to-clipboard MDX snippet:

```jsx
<span onClick={(e) => { e.preventDefault(); if (typeof navigator !== 'undefined') { navigator.clipboard.writeText('support@itsbandmath.com'); const originalText = e.target.innerText; e.target.innerText = 'Copied!'; setTimeout(() => e.target.innerText = originalText, 2000); } }} style={{cursor: 'pointer', color: 'var(--ifm-color-primary)', fontWeight: 'bold', textDecoration: 'underline'}} title="Click to copy email">support{'@'}itsbandmath.com</span>
```

### 4. Sidebar Hierarchy
Control document and category ordering explicitly:
* **Documents:** Set `sidebar_position: X` and `sidebar_label: ...` in YAML frontmatter.
* **Categories:** Add a `_category_.json` file inside the directory defining `label`, `position`, and `link`.

## 🌍 Localization & Search Engine Invariants

When working with translations (`LOCALIZATION_MASTER_PLAN.md`) or modifying site configuration:
1. **Local Search Configuration:** The search plugin (`@easyops-cn/docusaurus-search-local`) in `docusaurus.config.js` **must** declare all enabled locales in its `language` array (e.g. `['en', 'fr', 'de', 'es', 'pl']`). If omitted, search indexing will silently fail for non-English locales.
2. **AST Parsing for Translations:** Automated or AI translations must use AST parsing to translate text nodes only. Internal Markdown links (e.g., `[Link](./Path/To/Doc.md)`) must preserve their exact relative target paths to avoid breaking Docusaurus link validation.
