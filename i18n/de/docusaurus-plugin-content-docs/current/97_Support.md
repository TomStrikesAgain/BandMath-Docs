# Support Kontaktieren

Brauchst du Hilfe am Merch-Stand oder hast du eine Frage zur Abendabrechnung? Du erreichst unser Team direkt aus der App oder per E-Mail:

1. **In-App Support & Feedback:** Öffne die **Benutzereinstellungen (User Settings)** über die obere Navigationsleiste (im Band-, Venue- oder Tour-Manager-Modus) und tippe auf **Support / Feedback**. Sende eine Nachricht direkt an unser Team und wir antworten dir direkt per E-Mail.
2. **Direkte E-Mail:** Klicke, um unsere Support-Adresse zu kopieren, und schreibe uns jederzeit an <span onClick={(e) => { e.preventDefault(); if (typeof navigator !== 'undefined') { navigator.clipboard.writeText('support@itsbandmath.com'); const originalText = e.target.innerText; e.target.innerText = 'Copied!'; setTimeout(() => e.target.innerText = originalText, 2000); } }} style={{cursor: 'pointer', color: 'var(--ifm-color-primary)', fontWeight: 'bold', textDecoration: 'underline'}} title="Click to copy email">support{'@'}itsbandmath.com</span>.
