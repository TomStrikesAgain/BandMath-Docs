# Contactar con Soporte

¿Necesitas ayuda en el puesto de merch o tienes alguna pregunta sobre la liquidación de un concierto? Puedes contactar con nuestro equipo directamente desde la aplicación o por correo electrónico:

1. **Soporte y Comentarios en la App:** Abre **Ajustes de Usuario (User Settings)** en la barra superior (en modo Banda, Sala o Tour Manager) y pulsa **Support / Feedback**. Envía un mensaje directamente a nuestro equipo y te responderemos en tu bandeja de entrada.
2. **Correo Electrónico Directo:** Haz clic para copiar nuestra dirección de soporte y escríbenos en cualquier momento a <span onClick={(e) => { e.preventDefault(); if (typeof navigator !== 'undefined') { navigator.clipboard.writeText('support@itsbandmath.com'); const originalText = e.target.innerText; e.target.innerText = 'Copied!'; setTimeout(() => e.target.innerText = originalText, 2000); } }} style={{cursor: 'pointer', color: 'var(--ifm-color-primary)', fontWeight: 'bold', textDecoration: 'underline'}} title="Click to copy email">support{'@'}itsbandmath.com</span>.
